# rdnajac.github.io

This is the repository for my personal static website built using [Hugo](https://gohugo.io/)
hosted on [GitHub Pages](https://rdnajac.tech).

## Local Development

To run the site locally:

```bash
# Install Hugo (extended version)
# See https://gohugo.io/installation/

# Run the development server
hugo server

# Build the site
hugo
```

The site will be available at `http://localhost:1313/`.
